# Lumina Studio

Create a complete, premium, modern, highly attractive Interior Design & Architecture company website.

The website should feel luxurious, sophisticated, spacious, professional, and visually memorable — not like a generic template.

DESIGN DIRECTION

Use a premium interior design aesthetic inspired by modern luxury architecture studios.

Overall visual style:

Minimal but rich

Elegant and spacious

Editorial-style layouts

Strong visual hierarchy

Large premium photography

Smooth subtle animations

Rounded corners only where appropriate

Avoid excessive cards, boxes, gradients, and clutter

Use plenty of whitespace

Desktop design should feel cinematic

Mobile experience must remain clean and premium

COLOR PALETTE

Use a refined warm luxury palette:

Primary background:
#F6F2EC – soft warm ivory

Secondary background:
#EAE2D8 – light beige

Dark text / dark sections:
#1C1C1A – charcoal black

Primary accent:
#A47C59 – muted bronze / warm brown

Secondary accent:
#C9B49A – champagne beige

White:
#FFFFFF

Use dark sections strategically to create contrast.

Do not overuse the accent color.

TYPOGRAPHY

Use an elegant serif font for large headings such as:
Playfair Display / Cormorant Garamond / DM Serif Display

Use a clean modern sans-serif font for body text:
Inter / Manrope / Plus Jakarta Sans

Typography should feel editorial and premium.

Use large headings with strong line-height and elegant spacing.

ANIMATIONS

Use sophisticated animations throughout the website.

Animations should feel smooth and premium, not excessive.

Use:

Fade-up on scroll

Text reveal animations

Image mask reveals

Parallax images

Hover zoom

Smooth section transitions

Magnetic buttons

Animated underlines

Count-up statistics

Timeline progress animations

Smooth page scrolling

Image reveal on project cards

Use Framer Motion or GSAP if supported.

Animation timing:
0.4s – 0.8s

Use smooth easing:
cubic-bezier or ease-out

Do not make animations distracting.

INTERACTION DETAILS

Buttons:

Subtle scale animation

Animated arrow movement

Background transition on hover

Images:

Slow scale on hover

Project cards:

Cursor interaction

View Project label follows cursor if appropriate

Navbar:

Active section highlighting

Add custom smooth cursor only on desktop if it does not affect usability.

RESPONSIVENESS

Fully responsive for:
Desktop

Mobile

On mobile:

Reduce oversized headings appropriately

Stack layouts cleanly

Maintain proper spacing

Keep project images visually strong

PERFORMANCE

Optimize images.

Prevent layout shifts.

IMPORTANT

Do not create a generic template website.

Make the design feel like a real international premium interior architecture studio.

Prioritize:

Strong spacing

Luxury visual identity

Conversion-focused CTAs

The final result should look polished enough to be used by a real luxury interior design company.
